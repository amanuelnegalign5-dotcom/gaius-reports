# GAIUS Ministry Reports: permission-corrected package

Report visibility is limited to the six department leaders, Administrative and Finance Staff, Monday Staff Program Leader, Country Director, and International Director.

International Staff, Assisting Staff, and Prayer Staff do not receive the Reports navigation item and cannot render the report list. These roles retain access to attendance and Monday-program-related areas.

Upload every file in this folder to the GitHub repository root and replace the existing files. The service-worker cache name was changed so installed iPhone/Android PWAs receive the permission update.
