# GAIUS Ministry Reports PWA

Installable bilingual reporting app for iPhone, Android and desktop.

## Publish with GitHub Pages
1. Create a new public or private GitHub repository.
2. Upload every file and folder from this project, including `.github` and `.nojekyll`.
3. Use the `main` branch.
4. Open **Settings > Pages**.
5. Under **Build and deployment**, choose **GitHub Actions**.
6. Open the **Actions** tab and wait for the green deployment check.
7. Your link will be `https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/`.

## Install on iPhone
1. Open the GitHub Pages link in Safari.
2. Tap **Share**.
3. Tap **Add to Home Screen**.
4. Tap **Add**.

## Install on Android
1. Open the GitHub Pages link in Chrome.
2. Open the menu.
3. Tap **Install app** or **Add to Home screen**.

## Important data limitation
Accounts, reports and comments are stored on the current device. Different devices do not share data. To synchronize Staff and Director data across phones, connect Firebase Authentication and Cloud Firestore.
