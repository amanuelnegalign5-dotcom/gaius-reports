ጋይዮስ — የሪፖርት ሥርዓት
==============================

ይህ የራሱን ዳታ በመሣሪያው ላይ የሚያስቀምጥ የወርሃዊ ሪፖርት መተግበሪያ ነው። የመጀመሪያው HTML ፋይል የነበሩትን ዋና ዋና የሪፖርት መስኮችና ማጠቃለያዎች ይጠብቃል፤ የውጭ ዳታቤዝ ወይም የሶስተኛ ወገን መለያ አያስፈልገውም።

የሚሰሩ ባህሪያት
----------------
- ክንውን መመዝገብ፣ ማስተካከልና መሰረዝ
- ዳታን በተመረጠው ወርና ዓመት ማጣራት
- አጠቃላይ አፈጻጸም፣ የማዕከላትና ዲፓርትመንቶች ማጠቃለያ
- የክፍተትና የመረጃ ጥራት ፍተሻ
- CSV ማውረድ
- ሙሉ ዳታን JSON Backup ማድረግና Restore ማድረግ
- የወር ሪፖርት መቅዳት/ማጋራት
- ጨለማ/ብርሃን ገጽታ
- ከተጫነ በኋላ ከመስመር ውጭ (offline) መስራት

ፈጣን አጠቃቀም
----------------
1. index.html ን በዘመናዊ browser ይክፈቱ።
2. ወርና ዓመት ይምረጡ።
3. “አዲስ ክንውን +” በመጫን ቅጹን ይሙሉ።
4. ከዕቅድ በታች ከሆነ ምክንያት፣ እርምጃ፣ ኃላፊና የማጠናቀቂያ ቀን ያስፈልጋሉ።
5. ዳታው በዚያው browser ውስጥ በራስ-ሰር ይቀመጣል። CSV ለሪፖርት፣ Backup ደግሞ ለሙሉ ዳታ ጥበቃ ይጠቀሙ።

በ iPhone ላይ እንደ App ለመጫን
-------------------------------
የPWA መጫኛ (manifest + service worker) ባህሪው በHTTPS የተጠበቀ ድረ-ገጽ ላይ ሲሆን ይሰራል. ZIP ፋይሉን ወደ HTTPS hosting አገልግሎት ይጫኑ፤ ከዚያ በ iPhone Safari ያክፍቱ፣ Share → Add to Home Screen ይምረጡ። ከተጫነ በኋላ የተከማቸ ዳታ ከመስመር ውጭ ሊጠቀሙበት ይችላሉ።

አስፈላጊ የዳታ ጥንቃቄ
------------------------
- ይህ እትም የጋራ/Cloud ዳታቤዝ የለውም። ዳታው በአንድ መሣሪያና browser ላይ ብቻ ይቀመጣል።
- Browser data ካጸዱ፣ app data ካጠፉ ወይም መሣሪያ ከቀየሩ ዳታ ሊጠፋ ይችላል። በየጊዜው Backup ያውርዱ።
- በብዙ ሰዎች/ማዕከላት መካከል በቀጥታ ማመሳሰል ካስፈለገ የተጠበቀ የserver/database እትም ያስፈልጋል።
- የግል ወይም ሚስጥራዊ የተጠቃሚ መረጃዎችን አያስገቡ። በምክርና ድጋፍ ሪፖርት የጉዳይ ኮድ ይጠቀሙ።
